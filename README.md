## 已锁定核心规则
1. 报销年度采用年度账套，默认当前自然年，支持历史年度补登。
2. 创建下一年度账套时复制上一年度参数；历史年度账套可再次编辑，尤其允许调整“是否补登”。
3. 报销比例属于报销类型固定参数，不按年度配置；报销明细保存实际使用比例快照。
4. 年度额度为员工本人 + 合规子女年度总额。
5. 可用额度 = 年度额度 - 已通过金额 - 待审批金额。
6. 报销金额 = 个人自付 × 报销比例。
7. 男职工单数年、女职工双数年决定子女报销年度资格。
8. 退休人员直接识别为退休人员分类；非退休人员按发票姓名识别本人/子女。
9. 发票号码全局唯一；驳回后释放当前占用，历史审批记录保留。
10. 审批修改后的姓名/日期/个人自付必须重新执行业务校验。
