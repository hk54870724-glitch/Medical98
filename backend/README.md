# 企业医药费报销系统 - 后端最终版基础工程

## 已实现
- 登录 / Session / RBAC
- 员工查询
- 年度账套
- 年度额度
- 报销分类、类型、固定比例
- 报销申请事务
- 发票全局查重
- 职工/子女/退休人员识别
- 男职工单数年、女职工双数年
- 发票日期及员工生命周期校验
- 个人自付 × 报销比例
- 已通过 + 待审批额度占用
- 逐票审批 / 批量审批
- 驳回释放发票
- 管理员账套、规则、员工、子女、账号、系统参数
- CSV 导入
- 文本解析、文件保存、URL代理基础网关

## 运行
1. `npm ci`
2. `copy .env.example .env`
3. 配置 DATABASE_URL、SESSION_SECRET、FILE_STORAGE_ROOT
4. `npm run init`
5. `npm start`

## 注意
PDF/OFD真实解析、真实OCR识别需要在部署机继续接入对应解析库或OCR服务；本版本提供统一网关边界与文本正则兜底，不能把“未接入OCR服务”误认为已完成真实OCR识别。
