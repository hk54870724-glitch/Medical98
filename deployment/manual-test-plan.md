# 线下实际环境验收测试计划

## A. 环境检查
- Node.js 可执行
- npm 可执行
- PostgreSQL 服务运行
- 数据库连接成功
- `npm run init` 成功
- backend API `/api/v1/health` 返回 UP

## B. 账号
1. admin/admin123 登录。
2. finance01/finance123 登录。
3. 禁用账号后立即不能登录。
4. 修改初始密码后旧密码失效。

## C. 年度账套
1. 当前年度自动成为默认年度。
2. 创建下一年度账套时复制上一年度参数。
3. 指定历史年度修改“允许补登”。
4. 关闭补登后禁止新申请，不影响历史申请。

## D. 员工与子女
1. 工号不存在时不能申请。
2. 本人发票自动识别为职工医药费。
3. 已登记子女发票自动识别为子女医药费。
4. 未登记姓名禁止提交。
5. 男职工单数年允许子女报销，双数年禁止。
6. 女职工双数年允许子女报销，单数年禁止。
7. 退休人员直接识别为退休人员分类。

## E. 发票日期
覆盖：年度账套起止日、入职日前、离职后、合法边界日期。

## F. 额度
验证：
`年度额度 - 已通过 - 待审批 >= 本次申请`。
特别验证两个浏览器同时提交不会突破额度。

## G. 发票查重
- 同申请单重复
- 不同申请单重复
- 驳回后重新提交原号码

## H. 审批
- 单票通过
- 单票驳回
- 部分通过/部分待审批
- 全部驳回
- 审批修改姓名/日期/个人自付后重新校验
- 批量通过/驳回

## I. OCR/文件
- 文本粘贴解析
- PDF文本解析
- 图片OCR回退（需配置真实OCR服务）
- OFD解析（需配置真实解析库）
- URL代理SSR​​F阻断
- 文件落盘及下载权限

- UTF-8 CSV

- 已有工号覆盖更新
